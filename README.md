🎯 Project Overview

This To-Do App allows users to efficiently manage their daily tasks with a clean and intuitive interface. It includes advanced features such as task prioritization, filtering, progress tracking, and local storage persistence.

The project focuses on building real-world CRUD functionality using React and improving UI/UX using Tailwind CSS.

✨ Features
➕ Add New Tasks
✏ Edit Existing Tasks
🗑 Delete Tasks
✔ Mark Tasks as Completed / Pending
🔥 Priority System (High / Medium / Low)
📅 Task Due Date Selection
📊 Progress Bar (Completion Tracking)
🔍 Filter Tasks (All / Completed / Pending)
💾 LocalStorage Support (Data persists after refresh)
📱 Fully Responsive Design
🎨 Clean & Modern UI
